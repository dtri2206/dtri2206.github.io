# Tri Nguyen: personal homepage

Static site (HTML, CSS, vanilla JS, no build step) for the ESC Group page at UB.

- `index.html`: all text. `styles.css`: colors and type are tokens at the top. `script.js`: motion and the image viewer.
- `assets/img/headshot.jpg`: put the headshot here (portrait, about 4:5). Until then the page shows "TN".
- Run locally: `python3 -m http.server 8000`, then open http://localhost:8000.
